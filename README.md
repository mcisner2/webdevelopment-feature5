# ASL Awareness Project

Marcos Cisneros and Elijah Jones

## Description

The ASL Awareness Project is a React and Vite web application designed to promote awareness and education about American Sign Language (ASL). The application includes an ASL sign browser, an ASL history timeline, awareness resources, educational content, and Parse-backed data models.

ASL sign images are displayed as 28×28 grayscale images rendered dynamically on an HTML canvas. Sign data is loaded asynchronously from a Parse (Back4App) backend and presented through a searchable, sortable interface. For the purpose of feature 5, we have added authentication and protected routes, which are proved to be working through our home page and user creation, login, and log out processes.
